# Квоты провайдеров

Квота относится к аккаунту или проекту провайдера и учитывает работу других
приложений. Бюджет подписки Remote — отдельное ограничение владельца сервера.
Неизвестный остаток обозначается `—`, оценка — `≈`.

## Google Gemini

API-ключ генерации сам по себе не предоставляет авторизацию Google Monitoring.
Чат должен работать без настройки мониторинга.

Для проверки доступа:

1. Найдите проект ключа Gemini в [AI Studio](https://aistudio.google.com/projects).
2. Выберите именно этот проект в Google Cloud Console.
3. Проверьте право чтения метрик: роль `roles/monitoring.viewer` либо уже
   имеющиеся эквивалентные права. Для индикатора не нужна роль Editor.
4. Для локального эксперимента установите Google Cloud CLI и выполните
   `gcloud auth application-default login`.
5. Credentials содержат refresh token: храните их вне репозитория, не отправляйте
   в чат или на общий сервер. Отзыв: `gcloud auth application-default revoke`.

Это подготовка к проверке источника; наличие ADC ещё не доказывает доступность
метрик выбранного проекта. Local и серверный проект проверяются отдельно.
Не подключайте биллинг ради строки состояния. Требование включить оплату
означает, что бесплатный путь для этого проекта не подтверждён.

Google публикует метрики `generativelanguage.googleapis.com/quota/...`:
`limit` — GAUGE, `usage` — DELTA; метки включают модель и имя лимита.
Пределы семплируются раз в 60 секунд, видимость может задерживаться до 150 секунд.
Точное текущее RPM нельзя получить простым вычитанием запоздавших значений.
Разные тарифы, модели, минутные и суточные окна нельзя суммировать между собой.
RPD сбрасывается в полночь Pacific Time с учётом перехода на летнее время.
Наличие описания метрики не доказывает наличие ряда для конкретного проекта.
Пустой ответ не подтверждает нулевой расход или остаток.

Тариф и эффективные лимиты следует сверять с AI Studio, а не с таблицей
значений Free в коде. Для будущего опроса нужен ограниченный набор рядов,
кэш минимум на 5 минут и отдельный предел чтений; автоматический обход
всех метрик и частый фоновый опрос не нужны.

В опубликованном тарифе Monitoring чтение учитывается по числу возвращённых
временных рядов: первый миллион в месяц на billing account включён бесплатно,
далее $0.50 за миллион. Это не подтверждение доступности API без billing account;
доступ без оплаты необходимо проверить на самом проекте.

## Tavily

Источник — `GET https://api.tavily.com/usage` с Bearer-ключом активного режима.
Запрос не выполняет поиск. Он возвращает расход и предел аккаунта, тариф,
а также отдельный предел ключа. Pay-as-you-go не прибавляется к бесплатному
остатку. Неизвестный тариф или отсутствующие поля не означают наличие кредитов.
В Local используется личный ключ; в Remote — ключ сервера.
