# Просмотр и откат файловых правок

Перед записью файлов CLI выводит короткий список и спрашивает подтверждение
в основном экране. Окна выбора файлов/фрагментов и diff автоматически не открываются.
Отказ сохраняет файлы. После ответа остаётся сводка результатов записи.

`/diff` или `/undo` без аргументов показывает список активных изменённых файлов,
как `/attachments`. `/diff src/file.py` открывает только изменения этого файла:
стрелки и PgUp/PgDn прокручивают текст, / запускает поиск, Esc/q возвращает в чат.
Изменения нескольких последовательных ходов объединяются относительно исходной
версии файла. При ручном изменении между записями показываются отдельные цепочки
правок агента. Исходные ручные правки не считаются изменениями агента. Git не требуется.
Пути дополняются после `/diff ` и `/undo `; имя с пробелами вводится целиком,
например `/diff папка/мой файл.py`. Подсказки берутся только из журнала текущего чата.

Перед первой записью проверяется весь предложенный набор. Перед заменой каждого
файла проверка повторяется. Атомарность действует на один файл: при ошибке диска
или отмене часть набора может уже быть записана. Сводка показывает результат
каждого файла; `/undo` доступен для успешно применённых правок.

`/undo src/file.py` непосредственно восстанавливает исходные байты и права одного
файла до накопленных правок агента; созданный файл удаляется. Команда сама является
явным запросом на откат и не открывает дополнительные окна подтверждения.
Отменённый файл исчезает из `/diff`, `/undo` и подсказок. Остальные файлы остаются доступны.
Ручная правка, удаление, подмена ссылкой или смена прав после
записи агента блокирует откат соответствующего файла. Ручное изменение между
двумя записями агента в тот же файл также блокирует его откат.

Контрольные точки находятся в `~/.gemini_cli/checkpoints` (в Windows — в
каталоге профиля пользователя). Они имеют приватные права на POSIX, но не
шифруются. Предел — 64 МиБ, срок доступности — 7 дней; очистка выполняется
перед сохранением следующей точки. Отсутствующая или повреждённая точка
блокирует откат. Запрещённые секретные пути и ссылки не записываются.

Журнал хранится в памяти процесса для последних восьми сочетаний
режима/аккаунта, чата и рабочей папки. В нём сохраняются до 32 ходов с правками
и 64 МиБ снимков; обычное сообщение не стирает предыдущие изменения. При
превышении лимита CLI сообщает об освобождении старых ходов. Откат восстанавливает
файл до первого сохранённого изменения агента. После перезапуска журнал недоступен.
Произвольные shell-команды и внешние действия в журнал не входят.

Для ручной проверки в отдельной папке:

1. Измените файл вручную, затем попросите агента изменить два удалённых участка
   и создать второй файл. Убедитесь, что diff не открывается автоматически.
   Подтвердите запись в основном экране. Отправьте ещё одно сообщение: `/diff`
   должен по-прежнему показывать оба файла. Проверьте отказ от записи.
2. Откройте `/diff путь`, выполните поиск, измените размер терминала и вернитесь в чат.
   Проверьте прежний scrollback и отсутствие полной копии diff в нём.
3. Вызовите `/undo путь`: другой файл должен сохраниться, отменённый — исчезнуть
   из списка и подсказок. Повторите откат оставшегося файла: список должен стать пустым.
   Вручную измените записанный файл и попробуйте `/undo путь`: файл должен сохраниться.
4. Повторите в Local и Remote, на Linux и Windows. Эти действия не требуют
   отправки содержимого контрольных точек на сервер.
