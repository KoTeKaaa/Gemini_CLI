# Просмотр и откат файловых правок

Файловые инструменты сначала предлагают выбрать файлы и фрагменты. Пробел
включает фрагмент, Tab переводит фокус на кнопки. Далее можно записать выбранное,
посмотреть diff, изменить выбор или отменить запись. Diff открывается только по
действию «Посмотреть diff»: n/p переключают файлы, стрелки и PgUp/PgDn
прокручивают текст, / запускает поиск, Esc/q возвращает к подтверждению.
Невыбранные участки остаются исходными; пустой выбор ничего не записывает.

После ответа остаётся сводка. `/diff` открывает фактически записанные версии,
`/diff proposed` — исходные предложения, включая отклонённые. Изменения,
сделанные вручную до хода, не превращаются в правки агента. Git не требуется.

Перед первой записью проверяется весь выбранный набор. Перед заменой каждого
файла проверка повторяется. Атомарность действует на один файл: при ошибке диска
или отмене часть набора может уже быть записана. Сводка показывает результат
каждого файла; `/undo` доступен для успешно применённых правок.

`/undo` предлагает выбрать один или несколько файлов; по умолчанию ничего не
отмечено. Чтобы откатить весь набор, выберите «Все файлы».
После подтверждения выбранные файлы восстанавливают исходные байты и права,
а созданные файлы удаляются. Остальные доступны для следующего `/undo` этого хода.
Ручная правка, удаление, подмена ссылкой или смена прав после
записи агента блокирует откат соответствующего файла. Ручное изменение между
двумя записями агента в тот же файл также блокирует его откат.

Контрольные точки находятся в `~/.gemini_cli/checkpoints` (в Windows — в
каталоге профиля пользователя). Они имеют приватные права на POSIX, но не
шифруются. Предел — 64 МиБ, срок доступности — 7 дней; очистка выполняется
перед сохранением следующей точки. Отсутствующая или повреждённая точка
блокирует откат. Запрещённые секретные пути и ссылки не записываются.

Журнал хранится в памяти процесса для последних восьми сочетаний
режима/аккаунта, чата и рабочей папки. Новый ход заменяет предыдущий набор
в своём сочетании. После перезапуска старые точки не дают команду отката.
Произвольные shell-команды и внешние действия в журнал не входят.

Для ручной проверки в отдельной папке:

1. Измените файл вручную, затем попросите агента изменить два удалённых участка
   и создать второй файл. Убедитесь, что diff не открывается автоматически.
   Выберите один фрагмент, откройте diff по выбору, вернитесь и подтвердите запись;
   проверьте сохранность остального. Повторите запись без открытия diff и с отказом.
2. Откройте `/diff`, выполните поиск, измените размер терминала и вернитесь в чат.
   Проверьте прежний scrollback и отсутствие полной копии diff в нём.
3. Вызовите `/undo`, выберите один файл и подтвердите: другой должен сохраниться
   и остаться доступным для повторного отката. Проверьте отмену и пустой выбор.
   Вручную измените записанный файл, затем выберите «Все файлы»:
   изменённый файл должен сохраниться, остальные выбранные — восстановиться.
4. Повторите в Local и Remote, на Linux и Windows. Эти действия не требуют
   отправки содержимого контрольных точек на сервер.
