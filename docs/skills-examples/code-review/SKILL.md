Прочитай инструкции проекта и только выбранный пользователем diff.
Проверяй конкретные изменённые ветви и релевантные места вызова.
Сообщай подтверждённые ошибки с путём, строкой, условием возникновения
и наблюдаемым последствием. Не выдавай предпочтения стиля за ошибки.
Отдельно укажи реально выполненные проверки и непроверенные сценарии.
Не исправляй и не публикуй изменения без запроса пользователя.

Для расширенного списка вопросов пользователь может явно загрузить
`references/checklist.md`. Самостоятельный демонстрационный
`scripts/checklist.py` только печатает вопросы; он не анализирует код
и не нужен для ревью. Не запускай его автоматически.
