Уточни цель и критерий готовности по запросу пользователя и выбранным файлам.
Если данных достаточно, зафиксируй предположения и продолжай без вопросов.
Раздели работу на небольшие проверяемые шаги, назови затрагиваемые модули.
Укажи узкие проверки и реальные ограничения. Не заявляй выполненной работу,
которая ещё не сделана. Пользовательские инструкции имеют приоритет.

Если пользователь явно попросит шаблон, предложи прочитать `assets/plan.md`
через `/skill read assets/plan.md`. Автоматически ресурс не загружай.
