# 🚀 Gemini CLI 2.1 — веб-источники и точная работа с кодом

Gemini CLI стал удобнее для задач, где нужно найти документацию, разобраться
в проекте и аккуратно внести изменения — всё в привычном интерактивном терминале!

## 🌐 Поиск и документация рядом

- Добавлен Tavily Basic с источниками, бюджетом до трёх поисков на сообщение и кэшем повторов.
- Появилось чтение публичных HTML/plain-text страниц без расхода кредитов Tavily.
- CLI различает найденные и прочитанные источники и показывает конечные URL и усечение.
- При отсутствии ключа поиска обычный чат, чтение страниц и локальные инструменты продолжают работать.

## 🎯 Меньше лишнего текста, больше точности

- Поиск имён файлов и буквальный поиск текста помогают находить нужные участки проекта.
- Диапазоны строк возвращают только запрошенный фрагмент с номерами строк.
- Точечная замена показывает diff и требует отдельного подтверждения; неоднозначная замена отклоняется.
- Атомарная запись сохраняет права файла и исходные LF/CRLF при точечном редактировании.

## 🛡️ Надёжное продолжение и удобный запуск

- Клиент согласует доступные инструменты с сервером; прежние клиенты сохраняют свои три инструмента.
- Приватные аргументы и результаты новых файловых инструментов вычищаются из постоянной tool-истории.
- Ошибка одного инструмента не прерывает весь пакет, а лимит продолжений корректно закрывает последний batch.
- Адрес удалённого сервера без порта получает HTTPS и **9443**; явно заданные порты сохраняются.
- Исправлен русский вывод в перенаправленном Windows-терминале.

## 📦 Готовые сборки

- `gemini-cli-linux-x64` — Linux x64, сборка на Ubuntu 22.04; для запуска выполните `chmod +x gemini-cli-linux-x64`.
- `gemini-cli-windows-x64.exe` — Windows x64.
- `SHA256SUMS` — контрольные суммы обоих файлов.

Обе сборки проходят автономный запуск с временным профилем без серверных ключей
до публикации релиза. Для работы нужен адрес вашего FastAPI-сервера; ключи
Gemini, Supabase и Tavily остаются на сервере.
