# 🛠️ Gemini CLI 2.2.1 — надёжное автообновление сервера

Все возможности [Gemini CLI 2.2](https://github.com/KoTeKaaa/Gemini_CLI/releases/tag/v2.2.0)
сохраняются: Local и Remote, длинные диалоги, черновики, восстановление и потоковый Markdown!

## 🚀 Автодеплой без остановки на подготовке

- Исправлен поиск системной утилиты `runuser` при подготовке нового серверного окружения.
- Зависимости по-прежнему устанавливаются от пользователя службы, без ключей провайдеров в окружении сборки.
- Проверки точного коммита main, предварительный запуск кандидата и откат остаются обязательными.
- Установку программы автодеплоя на существующем сервере нужно обновить по [руководству](https://github.com/KoTeKaaa/Gemini_CLI/blob/v2.2.1/docs/auto-deploy.md).

## 📦 Linux и Windows

- `gemini-cli-linux-x64` — Linux x64.
- `gemini-cli-windows-x64.exe` — Windows x64.
- `SHA256SUMS` — контрольные суммы обеих сборок.

Обе сборки проходят проверку автономного запуска перед публикацией. Проверьте сумму
своего файла и запускайте привычный CLI — Local и Remote доступны без отдельной установки Python.
